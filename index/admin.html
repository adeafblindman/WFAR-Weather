HOW THIS WORKS: changes you make here save instantly to this browser only (GitHub Pages has no server, so there's no shared database). To make changes visible to every visitor, use Backup → Export Config below, then replace the contents of data.js's DEFAULT_PLANETS / DEFAULT_THEME / DEFAULT_SETTINGS in your repo with the exported values (or ask an assistant to do it for you) and push. Anyone who hasn't customized their own browser will then see your update. Uploaded icon/background images are stored as embedded data — keep them small, since browser local storage typically caps out around 5–10MB total.
